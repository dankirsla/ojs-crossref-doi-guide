# Setting Up Crossref DOIs in OJS: From Membership to First Deposit

A practical guide to configuring an Open Journal Systems (OJS) journal for DOI registration through Crossref, from obtaining a Crossref membership and DOI prefix to making the first deposit.

## What this guide covers

The guide explains the main steps involved in:

* obtaining a Crossref membership and DOI prefix
* configuring DOI settings in OJS
* enabling the relevant Crossref tools
* connecting OJS to Crossref
* preparing article metadata for deposit
* registering DOI records
* checking the results of a deposit
* understanding optional metadata and Crossref integrations

The guide distinguishes between required DOI-registration steps and optional integrations such as reference metadata, funding information, ORCID, ROR, and other Crossref-related services.

## OJS versions

OJS DOI workflows vary between versions. This guide identifies version-specific differences where they affect configuration or the deposit process.

The procedures should be checked against the current Crossref and PKP documentation before implementation.

## Scope and sources

This is a research-based technical guide derived from publicly available Crossref and PKP documentation and related technical resources. The procedures were not independently tested by the author unless explicitly stated.

Software interfaces, plugin names, configuration paths, Crossref requirements, and fees can change over time. Readers should verify current requirements and procedures with the relevant Crossref and PKP documentation before configuring a production journal.
